# שרת MoneyMate: סנכרון, בוט טלגרם ותזכורות

שרת קטן על Cloudflare Workers (חינמי לשימוש אישי). הוא נותן שלושה דברים:
1. **סנכרון** בין הטלפון למחשב.
2. **בוט טלגרם**: כותבים "קפה 18" וההוצאה נרשמת באפליקציה.
3. **תזכורות**: חד-פעמיות או חודשיות (ארנונה, ביטוחים), נשלחות אליך בטלגרם.

הנתונים נשמרים ב-KV של החשבון שלך. אל תעלה לריפו הציבורי טוקנים או נתונים אישיים.

## התקנה (פעם אחת, כ-10 דקות, ממחשב)

1. **בוט:** בטלגרם דבר עם `@BotFather`, שלח `/newbot` ושמור את ה-token.
2. **חשבון Cloudflare** חינמי: https://dash.cloudflare.com
3. בתיקיית `worker`:
   ```
   npm install -g wrangler
   wrangler login
   wrangler kv namespace create MM
   ```
   הדבק את ה-`id` שהתקבל ב-`wrangler.toml` במקום `REPLACE_WITH_KV_ID`.
4. **סודות** (כל פקודה תבקש ערך):
   ```
   wrangler secret put BOT_TOKEN        # מ-BotFather
   wrangler secret put SYNC_TOKEN       # מחרוזת אקראית ארוכה, תדביק אותה גם באפליקציה
   wrangler secret put WEBHOOK_SECRET   # עוד מחרוזת אקראית (אותיות ומספרים בלבד)
   ```
   ליצירת מחרוזת אקראית: `openssl rand -hex 24`
5. `wrangler deploy` ← תקבל כתובת כמו `https://moneymate-api.<שם>.workers.dev`
6. **חיבור הבוט לשרת** (החלף את הערכים):
   ```
   curl "https://api.telegram.org/bot<BOT_TOKEN>/setWebhook" \
     -d "url=https://moneymate-api.<שם>.workers.dev/tg" \
     -d "secret_token=<WEBHOOK_SECRET>"
   ```
7. שלח לבוט `/start`. הוא יענה עם מזהה הצ'אט שלך. שמור אותו:
   ```
   wrangler secret put ALLOWED_CHAT_ID
   wrangler deploy
   ```
   מעכשיו רק הצ'אט שלך מורשה.
8. **באפליקציה:** עוד ← "ענן, טלגרם ותזכורות" ← הדבק את כתובת השרת ואת `SYNC_TOKEN`.

## שימוש בבוט

| כתיבה | מה קורה |
|---|---|
| `קפה 18` | הוצאה, הקטגוריה נוחשת |
| `קפה 18 אוכל` | הוצאה עם קטגוריה |
| `+5000 משכורת` | הכנסה |
| `בטל` | מבטל רישום אחרון שעוד לא נקלט באפליקציה |
| `יתרה` / `תקציב` | סיכום החודש / מצב תקציבים |
| `תזכורת מחר 9:00 לקנות חלב` | תזכורת חד-פעמית |
| `תזכורת 20/11 18:30 תור לרופא` | בתאריך מסוים |
| `תזכורת בעוד שעתיים כביסה` | יחסית לעכשיו |
| `תזכורת כל חודש 10 לשלם ארנונה` | חוזרת מדי חודש |
| `תזכורות` / `מחק 2` | רשימה / מחיקה |

הזמנים לפי שעון ישראל.

## הערות

- סנכרון הוא "הכתיבה האחרונה מנצחת". אם שינית משני מכשירים לפני שסונכרנו, האפליקציה תשאל באיזו גרסה לבחור.
- הוצאות מהבוט מחכות בתור עד שהאפליקציה נפתחת, ואז נקלטות.
- בדיקת התראות רצה פעם בדקה ומשתמשת במכסה החינמית של Cloudflare, שמספיקה בהרבה לשימוש אישי.
